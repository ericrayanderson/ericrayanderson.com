# Style mockups

Three standalone looks for the home page and the Games page. They are not linked from the live site.

Open each `index.html` in a browser. Home and Games stay inside that style. About, Projects, Contact, and the playable games link back to the real pages.

| Folder | Style |
| --- | --- |
| `a/` | Clean and minimal. Near-white, system sans, quiet blue links. Light and dark. |
| `b/` | Playful and colorful. Rounded cards and a bright palette. Light and dark. |
| `c/` | Retro arcade. Dark neon with mono headings. Light is a readable fallback. |

Copy matches the cleanup: no placeholder card, a short Helicopter description, and Learning Terminal as phonics, typing, spelling, and number games for kids.
